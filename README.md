# كورس بايثون الشامل — من الصفر إلى الاحتراف

> Interactive Arabic Python course — one page, runs Python in your browser, works offline.

[![Made with Pyodide](https://img.shields.io/badge/Python%20in%20the%20browser-Pyodide-3776AB?logo=python&logoColor=white)](https://pyodide.org)
![Offline ready](https://img.shields.io/badge/Offline-Service%20Worker-4CAF50)
![Language](https://img.shields.io/badge/اللغة-العربية-orange)

كورس بايثون كامل بالعربي، من أول `print` لحد الاختبارات والبرمجة الكائنية ومدخل للذكاء الاصطناعي.
كل سطر كود مشروح، وتقدر **تجرّب الكود جوه الصفحة نفسها** من غير ما تنصّب أي حاجة على جهازك.

## ✨ مميزات الكورس

- **شغّل الكود في المتصفح:** بايثون حقيقي عن طريق Pyodide — من غير تنصيب.
- **يشتغل بدون إنترنت:** بعد أول زيارة، الـ Service Worker بيخزّن الكورس وملفات بايثون.
- **ملف واحد:** الكورس كله في `index.html`، سهل تفتحه أو تستضيفه في أي مكان.
- **بالعربي بالكامل** مع دعم اتجاه الكتابة من اليمين لليسار.

## 📚 محتوى الكورس

1. أول خطوة في الكود: الطباعة، المتغيّرات، والأنواع
2. النصوص بعمق: الفهرسة، التقطيع، والدوال الجاهزة
3. القرارات: `if` و `elif` و `else`
4. القوائم (Lists): تخزين مجموعة قيم في متغيّر واحد
5. حلقة `for`: كرّر الشغل من غير ما تكرّر الكود
6. المكتبات والعشوائية: استخدم شغل غيرك
7. حلقة `while`: كرّر لحد ما يحصل شرط
8. معالجة الأخطاء: خلّي برنامجك ما يقعش
9. القواميس والمجموعات: بيانات منظّمة بأسماء
10. الدوال: نظّم كودك وأعد استخدامه
11. مشاريع كبيرة: كل حاجة اتعلّمتها في مكان واحد
12. المكتبات الخارجية والـ APIs: وصّل برنامجك بالعالم
13. البرمجة الكائنية (OOP): اعمل أنواعك بنفسك
14. الاختبارات: إزاي تتأكّد إن كودك شغّال فعلًا
15. المراجع السريعة وخريطة طريقك الجاية

## 🚀 إزاي تشغّله

**أونلاين:** افتح صفحة الكورس من GitHub Pages بعد تفعيلها من إعدادات المستودع.

**محليًا:** لازم تشغّله من خادم (الـ Service Worker مش بيشتغل مع `file://`):

```bash
git clone https://github.com/Mohammedkhaled96/python-zero-to-pro.git
cd python-zero-to-pro
python -m http.server 8000
```

بعدها افتح `http://localhost:8000` في المتصفح.
