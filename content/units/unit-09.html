معالجة الأخطاء: خلّي برنامجك ما يقعش

كل البرامج اللي كتبناها لحد دلوقتي هشّة: أي مستخدم يكتب حرف مكان رقم والبرنامج بيقع برسالة حمرا مخيفة. الوحدة دي بتحوّل برامجك من «تجارب» لـ برامج حقيقية تتحمّل أخطاء المستخدم. ودي الفرق الحقيقي بين الهاوي والمحترف.

أنواع الأخطاء التلاتة درس 44

الهدف: تعرف تشخّص الخطأ قبل ما تحاول تصلّحه.

1. خطأ التركيب (SyntaxError)

print("hello"          # نسينا القوس
if x = 5:              # علامة = بدل ==
    print("hi"

من الوحدة صفر: بايثون بتكتشفه في مرحلة التحليل، قبل ما ينفّذ أي سطر. البرنامج مش هيشتغل خالص. رسالة الخطأ بتقول لك رقم السطر تقريبًا.

💡 نصيحة

لو بايثون قالت لك SyntaxError في سطر 20 والسطر مظبوط، بصّ على السطر 19. غالبًا قوس مش مقفول في السطر اللي قبله.

2. خطأ وقت التنفيذ (Runtime Error / Exception)

print("البرنامج بدأ")
result = 10 / 0            # 💥 ZeroDivisionError
print("ده مش هيتطبع")
▸ الناتج
البرنامج بدأ
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    result = 10 / 0            # 💥 ZeroDivisionError
             ~~~^~~
ZeroDivisionError: division by zero

لاحظ إن السطر الأول اشتغل فعلًا قبل ما البرنامج يقع. دي بالظبط طبيعة اللغة المفسّرة اللي اتكلمنا عنها في الوحدة صفر. النوع ده هو اللي هنتعلّم نتعامل معاه في الوحدة دي.

3. الخطأ المنطقي (Logical Error) — الأخطر

scores = [80, 90, 100]
average = sum(scores) / len(scores) - 10     # نسينا الأقواس
print(average)      # 80.0 بدل 90.0 — مفيش أي رسالة خطأ!
▸ الناتج
80.0

البرنامج اشتغل تمام، ما قالش أي حاجة، والنتيجة غلط. النوع ده ما بيتكشفش غير بالاختبار والتفكير — وtry/except ما بتنفعش معاه خالص.

4. إزاي تقرا رسالة الخطأ (Traceback)

🧠 نصيحة تفرق معاك جدًا

اقرا آخر سطر الأول. فيه نوع الخطأ وشرحه. وبعدين ارجع للسطر اللي قبله عشان تعرف مكانه. أغلب المبتدئين بيخافوا من النص الأحمر ويقفلوه — وده أسوأ حاجة ممكن تعملها. الرسالة دي صديقك، هي بتقول لك المشكلة فين بالظبط.

try و except: القبض على الأخطاء درس 45 · مهم جدًا

الهدف: تخلّي برنامجك يتعامل مع الخطأ بدل ما يقع.

1. الفكرة

try:
    user = int(input("Please enter a number\n"))
    print(user)
except ValueError:
    print("Invalid input, please write numbers only")
▸ الناتج (لو كتب abc)

الترجمة الحرفية: «جرّب تعمل ده… ولو حصل خطأ من نوع كذا، اعمل ده بدلًا منه».

  try:
      كود ممكن يفشل          ← بايثون بتنفّذه وهي «حاطة إيدها على قلبها»

      كود الطوارئ            ← بيتنفّذ بس لو حصل ValueError

  ┌──────────────────────────────────────────┐
  │ لو مفيش خطأ  → كتلة except بتتخطّى تمامًا │

  │                والسطور الباقية في try     │
  │                بتتخطّى                     │
  └──────────────────────────────────────────┘

3. قاعدة ذهبية: خلّي كتلة try صغيرة

# ❌ سيّئ: كل حاجة جوّه try

    age = int(input("السن: "))

⚠️ كتلة try الكبيرة بتخبّي الأخطاء

لو حطّيت 20 سطر جوّه try، لما يحصل خطأ مش هتعرف مين اللي سبّبه. خلّي الـ try حوالين الجزء الخطر بس.

4. الوصول لتفاصيل الخطأ بـ as

try:
    result = 10 / 0
except Exception as e:
    print(f"حدث خطأ: {e}")
    print(f"نوعه: {type(e).__name__}")
▸ الناتج

as e بتخزّن كائن الخطأ في متغيّر اسمه e، وطباعته بتدّيك شرح الخطأ. مفيدة جدًا في التطوير.

ملاحظات نقدية

  • الـ ZeroDivisionError الاحتياطية: إحنا أصلًا بنفحص second_number == 0 بالـ if، فنظريًا الـ except دي مش هتشتغل أبدًا. وجودها مش ضار — دي «حزام أمان تاني».
  • الـ except Exception الأخيرة: ممتازة كملجأ أخير. لاحظ إنها آخر واحدة — لو حطّيتها الأول هتبلع كل الأخطاء والـ except اللي تحتها ما تشتغلش أبدًا.
  • موقع سؤال «تحسب تاني؟»: بره الـ try، وقبله continue في كل except. يعني لو حصل خطأ، البرنامج بيرجع للحسبة على طول من غير ما يسأل — سلوك منطقي.
  • عيب: لو المستخدم غلط في العملية بس (كتب %)، بيضطر يدخل الرقمين تاني. تحسين ممكن: افصل السؤال في حلقة تحقّق لوحده.

except Exception هي الأب لكل الاستثناءات، وهي مكتوبة أول واحدة. فبايثون هتمسك بيها كل خطأ، والـ except اللي تحتها مش هتشتغل أبدًا.

في الواقع بايثون 3 بترفض الكود ده أصلًا وبترمي SyntaxError: default 'except:' must be last في بعض الحالات، أو بتتجاهل الفروع الميتة.

القاعدة: من الأخصّ للأعمّ. Exception دايمًا آخر واحدة.

try:
    x = int(input("رقم: "))
    print(10 / x)
except ValueError:
    print("مش رقم")
except ZeroDivisionError:
    print("قسمة على صفر")
except Exception as e:
    print(f"خطأ عام: {e}")

import random, string
def ask_number(message):
    """بتفضل تسأل لحد ما تاخد رقم صحيح موجب"""
    while True:
        try:
            value = int(input(message))
            if value < 0:
                print("لازم رقم موجب")
                continue
            return value
        except ValueError:
            print("أرقام بس من فضلك")
while True:
    length = ask_number("طول كلمة السر: ")
    letters = ask_number("عدد الحروف: ")
    numbers = ask_number("عدد الأرقام: ")
    symbols = ask_number("عدد الرموز: ")
    if letters + numbers + symbols == length:
        break
    print(f"⚠️ المجموع {letters+numbers+symbols} مش مساوي {length}، جرّب تاني\n")
password = (random.choices(string.ascii_letters, k=letters) +
            random.choices(string.digits, k=numbers) +
            random.choices(string.punctuation, k=symbols))
random.shuffle(password)
print(f"\nكلمة السر: {''.join(password)}")
