الدوال: نظّم كودك وأعد استخدامه

لحد دلوقتي كل برامجنا كتلة واحدة طويلة. الدوال بتخلّيك تقسّم البرنامج لقطع صغيرة، كل قطعة ليها مهمّة واحدة واسم واضح. دي مش رفاهية — دي الفرق بين برنامج من 50 سطر وبرنامج من 5000 سطر.

  1. عدم التكرار (DRY): اكتبها مرّة، استخدمها مليون.

النطاق (Scope): وين المتغيّر شغّال؟ درس 59

الهدف: تفهم ليه متغيّر جوّه دالة مش موجود بره — وربطها بالـ Stack.

1. المتغيّر المحلّي (Local)

def my_function():
    message = "أنا جوّه الدالة"
    print(message)
my_function()
print(message)        # ❌ NameError: name 'message' is not defined

ارجع لدرس Stack و Heap: لما تنادي دالة، بايثون بتحط إطار (frame) جديد فوق الـ Stack فيه متغيّرات الدالة. لما الدالة تخلّص، الإطار بيتشال — والمتغيّرات بتختفي.

  │ global             │            │ global             │

3. قاعدة LEGB — ترتيب البحث عن المتغيّر

  بايثون بتدوّر على المتغيّر بالترتيب ده:

  L → Local        جوّه الدالة الحالية
  E → Enclosing    في الدالة اللي محتواها (لو متداخلة)
  G → Global       في مستوى الملف
  B → Built-in     دوال بايثون الجاهزة (print, len …)

  أول ما تلاقيه بتقف.
قاعدة LEGB
x = "global"
def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)       # local
    inner()
    print(x)           # enclosing
outer()
print(x)               # global
▸ الناتج
local
enclosing
global

def apply_discount(price, percent=10, *, min_price=0):
    if not 0 <= percent <= 100:
        raise ValueError(f"نسبة غير صالحة: {percent}")
    result = round(price * (1 - percent / 100), 2)
    return max(result, min_price)

def chunks(items, size):
    if size < 1:
        raise ValueError("size لازم يكون 1 أو أكتر")
    for start in range(0, len(items), size):
        yield items[start:start + size]

⭐⭐⭐تمرين 6 — دوال ترجّع أكتر من قيمة

اكتب دالة analyze(numbers) ترجّع (المجموع، المتوسط، الأصغر، الأكبر) وتتعامل مع القائمة الفاضية من غير ما تقع.

شوف الحل 
def analyze(numbers):
    """بترجّع (المجموع، المتوسط، الأصغر، الأكبر)"""
    if not numbers:
        return 0, 0, None, None
    total = sum(numbers)
    return total, total / len(numbers), min(numbers), max(numbers)
total, avg, low, high = analyze([10, 20, 30])
print(f"المجموع {total} — المتوسط {avg:.1f} — من {low} لـ {high}")
print(analyze([]))     # (0, 0, None, None)

السبب: القيمة الافتراضية بتتقيّم مرّة واحدة وقت تعريف الدالة، مش مع كل استدعاء. فالقائمة دي كائن واحد في الـ Heap بيتشارك بين كل الاستدعاءات. 

def add_student(name, classroom=None):     # ✅ الحل
    if classroom is None:
        classroom = []
    classroom.append(name)
    return classroom

القاعدة: ما تستخدمش قيمة mutable (قائمة/قاموس) كقيمة افتراضية أبدًا.
