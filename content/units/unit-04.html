القرارات: if و elif و else

لحد دلوقتي كل برامجنا بتمشي في خط مستقيم من فوق لتحت. الوحدة دي بتدّي البرنامج القدرة على الاختيار — يقرأ الموقف ويقرّر يعمل إيه. من هنا بيبدأ البرنامج يبقى «ذكي».

عوامل المقارنة والقيم المنطقية درس 18

الهدف: تكوّن سؤال بايثون تقدر تجاوب عليه بـ True أو False.

1. عوامل المقارنة الستة

العاملمعناهمثالالنتيجة

!=لا يساوي5 != 3True
>أكبر من5 > 3True
<أصغر من5 < 3False
>=أكبر من أو يساوي5 >= 5True
<=أصغر من أو يساوي3 <= 5True
💥 = ولّا ==؟ — أشهر خطأ على الإطلاق
age = 18       # إسناد: حط 18 في المتغيّر age
age == 18      # مقارنة: هل age يساوي 18؟ → True/False

علامة واحدة = بتحط قيمة. علامتين = بتسأل سؤال. لو كتبت if age = 18: بايثون هترمي SyntaxError. الجميل إنها بتمسكه بدري، بعكس لغات تانية بتقبله وتديك نتيجة غلط.

2. المسافات البادئة (Indentation) — مش شكل، ده قانون

🧠 الفرق الأكبر بين بايثون وباقي اللغات

في لغات زي C و Java و JavaScript، بيستخدموا أقواس { } عشان يحدّدوا الكتلة (block). بايثون بتستخدم المسافة البادئة نفسها. يعني المسافات مش تجميل — دي جزء من قواعد اللغة، ولو غلطت فيها البرنامج ما يشتغلش. 

if 5 > 3:
    print("الأول جوّه")      # ← جوّه الـ if
    print("التاني جوّه")     # ← جوّه الـ if برضه
print("ده بره خالص")         # ← بره، بيشتغل دايمًا
▸ الناتج
الأول جوّه
التاني جوّه
ده بره خالص
💥 أخطاء المسافات
if 5 > 3:
print("hi")            # ❌ IndentationError: expected an indented block
if 5 > 3:
    print("a")
      print("b")       # ❌ IndentationError: unexpected indent

القاعدة: 4 مسافات لكل مستوى، وثابتة في الملف كله. ما تخلطش بين Tab والمسافات — VS Code بيحوّل الـ Tab لـ 4 مسافات تلقائيًا وده اللي عايزينه.

score = 75

    print("ممتاز")

▸ الناتج

⚠️ الترتيب مهم جدًا في elif

بايثون بتفحص الشروط بالترتيب من فوق لتحت، وبتقف عند أول شرط صح. الدرجة 75 بتحقّق >= 70 و>= 60، لكن بايثون وقفت عند الأولى ونفّذتها بس.

لو عكست الترتيب وبدأت بـ score >= 60، كل الدرجات فوق 60 هتطلع «مقبول»! ابدأ دايمًا بالشرط الأضيق.

5. if / elif / else مقابل if / if / if

# نسخة 2: if منفصلة — كلها بتتفحص

الخلاصة: استخدم elif لما الاحتمالات متنافية (لازم واحد بس). واستخدم if منفصلة لما عايز تفحص حاجات مستقلة.

الشروط المتداخلة (Nested if) درس 20

الهدف: تبني قرارات بتعتمد على قرارات قبلها.

1. الفكرة

أحيانًا السؤال التاني ما ينفعش يتسأل غير بعد جواب السؤال الأول. مثال: «هل عندك رخصة؟» ما ينفعش تتسأل قبل «هل سنك فوق 18؟». 

gender = input("Please enter your gender: male/female").lower()
if gender == "male":
    age = int(input("Please enter your age\n"))
    if age >= 18:
        print("You are an old man")
    else:
        print("You are a small man")
else:
    age = int(input("Please enter your age"))
    if age >= 18:
        print("You are a pretty woman")
    else:
        print("You are a pretty rose")
▸ الناتج

Please enter your age

2. قراءة الكود كشجرة قرار

                    gender?
                   /        \
              male            غير كده
              /                    \
           age?                    age?
          /    \                  /     \
      >= 18   < 18            >= 18    < 18
        │       │               │        │
    old man  small man   pretty woman  pretty rose
كل مستوى مسافة بادئة = مستوى في الشجرة

لاحظ مستويات المسافات: if gender على مستوى 0، وage = input() على مستوى 1 (4 مسافات)، وprint اللي جوّه if age على مستوى 2 (8 مسافات).

3. ملاحظات نقدية على الكود ده

⚠️ فيه تكرار

سطر age = int(input(...)) مكرّر مرّتين، وده اتكتب مرّة بـ \n ومرّة من غيرها. القاعدة الذهبية DRY (Don't Repeat Yourself) بتقول: لو نفس السطر متكرّر، اطلعه بره. 

gender = input("Please enter your gender (male/female): ").strip().lower()
age = int(input("Please enter your age: "))     # مرّة واحدة بره
if gender == "male":
    print("You are an old man" if age >= 18 else "You are a small man")
elif gender == "female":
    print("You are a pretty woman" if age >= 18 else "You are a pretty rose")
else:
    print("Invalid gender, please write male or female")

كمان النسخة الجديدة ضافت else نهائي للتعامل مع المدخل الغلط — في النسخة الأصلية أي حاجة مش male كانت بتتحسب female تلقائيًا، وده منطق ناقص.

4. متى تتجنّب التداخل؟

التداخل العميق (3 مستويات فأكتر) بيخلّي الكود صعب القراية. لو لقيت نفسك بتعشّش كتير، فكّر في:

  • دمج الشروط بـ and: if gender == "male" and age >= 18:
  • استخدام elif بدل else + if.
  • تقسيم الكود لدوال (الوحدة 11).

مشروع 5: الآلة الحاسبة الشرطية ◆ مشروع

الهدف: التطوير التاني للحاسبة — المستخدم يختار العملية اللي عايزها بس.

operator = input("Please enter your operator do you want\n")

if operator == "+":

elif operator == "-":
    print(f"your process is:\n{first_number - second_number}")
elif operator == "*":
    print(f"Your process is:\n{first_number * second_number}")
elif operator == "/":
    if second_number == 0:
        print("you do not be able to divide by 0")
    else:
        print(f"Your process is:\n{first_number / second_number}")
else:
    print("Invalid choice")

الشرح

  • سلسلة elif: بايثون بتفحص العملية واحدة واحدة وبتوقف عند أول تطابق. لو كتب + ما هتفحصش باقي الشروط أصلًا.
  • الـ if المتداخلة في حالة القسمة: دي أهم نقطة في المشروع. القسمة على صفر ممنوعة رياضيًا، وبايثون بترمي ZeroDivisionError وبيقع البرنامج. فبنفحص الأول قبل ما نقسم.
  • الـ else النهائي: شبكة أمان — لو المستخدم كتب % أو أي حاجة مش معروفة، البرنامج بيقول له بدل ما يسكت.
ℹ️ ملاحظة على الكود الأصلي

في النسخة الأصلية الشرط كان مكتوب if second_number == 0 and operator == "/":. الجزء التاني زايد — إحنا أصلًا جوّه فرع elif operator == "/"، فمن المستحيل نوصل هنا والعملية مش قسمة. شيلناه في النسخة اللي فوق. الدرس: شرط زايد مش بيكسر البرنامج، بس بيوحّش قراءته ويوهم القارئ إن فيه احتمال تاني.

elif operator == "-":
    print(first_number - second_number)
elif operator == "*":
    print(first_number * second_number)
elif operator == "**":
    print(first_number ** second_number)
elif operator in ["/", "%"]:
    if second_number == 0:
        print("you do not be able to divide by 0")

مشروع 6: مستشار الملابس حسب الطقس ◆ مشروع

الهدف: أكبر تطبيق على الشروط المتداخلة — شجرة قرار من مستويين.

الفكرة

البرنامج بيسأل عن حالة الجو، وبناءً على الإجابة بيسأل سؤال تاني أدق، وبعدين بيدّي نصيحة مناسبة للحالة بالظبط. 

print("مرحبا بك, نرجو لك الاستفادة الكاملة من برنامجنا")

print(f"أها!, إذن حالة الطقس لديك:\n{weather}, نرجو لك صحةً جيدة")
if weather == "مشمس":
    sunny_question = input("هل الجو حار أم دافئ أم معتدل؟:\n")
    if sunny_question == "حار":
        print("إذن عليك بارتداء الملابس الخفيفة")
    elif sunny_question == "دافئ":
        print("إذن عليك بارتداء الملابس غير الرسمية المريحة")
    elif sunny_question == "معتدل":
        print("إذن عليك بارتداء ملابس زيا ذا طبقات متعددة")
elif weather == "ممطر":
    rainy_question = input("إذن هل المطر خفيف أم غزير\n")
    if rainy_question == "خفيف":
        print("إذن عليك بارتداء سترة مقاومة للماء")
    elif rainy_question == "غزير":
        print("إذن عليك بارتداء ملابس ثقيلة تقاوم المطر الشديد")
elif weather == "ثلجي":
    snowy_question = input("إذن هل العواصف الثلجية خفيفة أم شديدة\n")
    if snowy_question == "خفيفة":

else:
    print("أوه لا!, حالة الطقس التي أدخلتها غير صحيحة, من فضلك أعد المحاولة")

الثغرة الخفيّة في الكود ده

💥 لو المستخدم كتب إجابة تانية في السؤال الداخلي

لو اختار «مشمس» وبعدين كتب «برد» في السؤال التاني، البرنامج هيسكت خالص وما يطبعش أي حاجة. السبب إن الـ if الداخلية مالهاش else.

القاعدة: كل سلسلة if/elif بتتعامل مع مدخلات مستخدم لازم يكون ليها else. البرنامج اللي بيسكت أسوأ من البرنامج اللي بيقع، لأنه بيخلّي المستخدم تايه.

النسخة المحسّنة

print("مرحبا بك في مستشار الملابس")
weather = input("ما هي حالة الجو: مشمس / ممطر / ثلجي؟ ").strip()
if weather == "مشمس":
    level = input("هل الجو حار أم دافئ أم معتدل؟ ").strip()
    if level == "حار":
        print("الملابس الخفيفة القطنية")
    elif level == "دافئ":
        print("ملابس غير رسمية مريحة")
    elif level == "معتدل":
        print("ملابس بطبقات متعددة")
    else:
        print("إجابة غير معروفة, اختر: حار / دافئ / معتدل")
elif weather == "ممطر":
    level = input("هل المطر خفيف أم غزير؟ ").strip()
    if level == "خفيف":
        print("سترة مقاومة للماء")
    elif level == "غزير":
        print("ملابس ثقيلة مقاومة للمطر ومظلة")
    else:
        print("إجابة غير معروفة, اختر: خفيف / غزير")
elif weather == "ثلجي":
    level = input("هل العاصفة خفيفة أم شديدة؟ ").strip()
    if level == "خفيفة":
        print("معطف وحذاء شتوي")
    elif level == "شديدة":
        print("ملابس وأحذية شتوية ثقيلة, وانتبه لسلامتك")
    else:
        print("إجابة غير معروفة, اختر: خفيفة / شديدة")
else:
    print("حالة الطقس غير صحيحة. الخيارات: مشمس / ممطر / ثلجي")

التحسينات: .strip() على كل مدخل، وelse في كل مستوى، واسم متغيّر موحّد level.

🧠 لسه ناقصنا حاجة كبيرة

لو المستخدم غلط، البرنامج بيقفل ولازم يشغّله من الأول. الحل الطبيعي إننا نكرّر السؤال لحد ما يدخل إجابة صح — وده محتاج while في الوحدة 8. هنرجع للمشروع ده هناك.

تحدّيات بتصحيح آلي: الوحدة الرابعة 🧪 تحدّي

القرارات: الاختبارات بتجرّب الحالات الحدّية (90 بالظبط؟ 100؟ -1؟) — المكان اللي أغلب الأخطاء بتستخبّى فيه.

🧪 التحدّي 1 — التقدير ⭐⭐

اطلب درجة (رقم صحيح). اطبع: A من 90، B من 80، C من 70، D من 60، غير كده F. ولو الدرجة أقل من 0 أو أكبر من 100 اطبع درجة غير صالحة.

شوف الحل النموذجي 
score = int(input("الدرجة: "))
if score < 0 or score > 100:
    print("درجة غير صالحة")
elif score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
🐞 التحدّي 2 — السنة الكبيسة ⭐⭐⭐

السنة كبيسة لو بتقبل القسمة على 4 ومش على 100 — إلا لو بتقبل القسمة على 400. (2024 كبيسة، 1900 مش كبيسة، 2000 كبيسة). الكود ده بيغلط في حالة. لاقيها وصلّحها.

شوف الحل النموذجي 
year = int(input("السنة: "))
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("كبيسة")
else:
    print("مش كبيسة")

تمارين الوحدة الرابعة ✍️ تدريب

الشروط هي عقل البرنامج. اتمرّن لحد ما تبقى بديهية.

المستوى الأول

⭐تمرين 1 — زوجي ولا فردي

اطلب رقم واطبع «زوجي» أو «فردي».

شوف الحل 
n = int(input("رقم: "))
if n % 2 == 0:
    print("زوجي")
else:
    print("فردي")
⭐تمرين 2 — الأكبر في تلاتة

اطلب 3 أرقام واطبع الأكبر — من غير ما تستخدم max().

شوف الحل 
a = int(input("الأول: "))
b = int(input("التاني: "))
c = int(input("التالت: "))
if a >= b and a >= c:
    print(f"الأكبر: {a}")
elif b >= a and b >= c:
    print(f"الأكبر: {b}")
else:
    print(f"الأكبر: {c}")
⭐تمرين 3 — التقديرات

اطلب درجة من 100 واطبع التقدير: 90+ ممتاز، 80+ جيد جدًا، 70+ جيد، 60+ مقبول، أقل راسب. وتعامل مع الدرجات غير المنطقية (أقل من 0 أو أكبر من 100).

شوف الحل 
score = int(input("الدرجة: "))
if score < 0 or score > 100:
    print("درجة غير صحيحة")
elif score >= 90:
    print("ممتاز")
elif score >= 80:
    print("جيد جدًا")
elif score >= 70:
    print("جيد")
elif score >= 60:
    print("مقبول")
else:
    print("راسب")

لاحظ: فحص الصلاحية جه الأول. لو حطّيته آخر حاجة، الدرجة 150 كانت هتطلع «ممتاز».

المستوى الثاني

⭐⭐تمرين 4 — سنة كبيسة

اطلب سنة وحدّد هل هي كبيسة. القاعدة: تقبل القسمة على 4، إلا لو قبلت على 100 ومقبلتش على 400.

شوف الحل 
year = int(input("السنة: "))
if year % 400 == 0:
    leap = True
elif year % 100 == 0:
    leap = False
elif year % 4 == 0:
    leap = True
else:
    leap = False
print(f"{year} {'كبيسة' if leap else 'غير كبيسة'}")
# أو في سطر واحد:
leap = (year % 4 == 0 and year % 100 != 0) or year % 400 == 0

جرّبها على 2000 (كبيسة)، 1900 (لأ)، 2024 (كبيسة)، 2023 (لأ).

⭐⭐تمرين 5 — تسجيل الدخول

اطلب اسم مستخدم وكلمة سر. الدخول ينجح لو الاسم «admin» والسر «1234». وميّز في الرسالة بين «الاسم غلط» و«السر غلط».

شوف الحل 
username = input("اسم المستخدم: ").strip().lower()
password = input("كلمة السر: ").strip()
if username != "admin":
    print("❌ اسم المستخدم غير موجود")
elif password != "1234":
    print("❌ كلمة السر غلط")
else:
    print("✅ أهلًا بك")
⚠️ ملاحظة أمنية

في نظام حقيقي، ما تقولش للمستخدم أنهي واحد غلط — قول «بيانات غير صحيحة» بس. لأن التمييز بيساعد المهاجم يعرف الأسماء الموجودة فعلًا. التمرين ده تعليمي بس.

⭐⭐تمرين 6 — حاسبة الشحن

اطلب وزن الشحنة والمدينة. السعر: القاهرة 30 جنيه، الإسكندرية 45، أي مدينة تانية 60. وزيادة 10 جنيه لكل كيلو فوق 5 كيلو.

شوف الحل 
weight = float(input("الوزن بالكيلو: "))
city = input("المدينة: ").strip()
if city == "القاهرة":
    base = 30
elif city == "الإسكندرية":
    base = 45
else:
    base = 60
extra = 0
if weight > 5:
    extra = (weight - 5) * 10
print(f"سعر الشحن: {base + extra:.2f} جنيه")

المستوى الثالث

⭐⭐⭐تمرين 7 — مثلث صحيح؟

اطلب 3 أطوال أضلاع. حدّد: (أ) هل يكوّنوا مثلث أصلًا؟ (مجموع أي ضلعين أكبر من التالت) (ب) لو أيوة، نوعه: متساوي الأضلاع / متساوي الساقين / مختلف الأضلاع.

شوف الحل 
a = float(input("الضلع الأول: "))
b = float(input("الضلع الثاني: "))
c = float(input("الضلع الثالث: "))
if a <= 0 or b <= 0 or c <= 0:
    print("الأطوال لازم تكون موجبة")
elif a + b <= c or a + c <= b or b + c <= a:
    print("مش مثلث صحيح")
elif a == b == c:
    print("مثلث متساوي الأضلاع")
elif a == b or b == c or a == c:
    print("مثلث متساوي الساقين")
else:
    print("مثلث مختلف الأضلاع")

لاحظ a == b == c — سلسلة المقارنات اللي بايثون بتسمح بيها.

قبل ما تكمّل، علّم على اللي تقدر تعمله بثقة. اللي مش متأكّد منه ارجع لدرسه — التقدّم بيتحفظ على جهازك.
