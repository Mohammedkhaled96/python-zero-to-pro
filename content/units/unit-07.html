المكتبات والعشوائية: استخدم شغل غيرك

المبرمج الشاطر مش اللي بيكتب كل حاجة من الصفر — هو اللي بيعرف إن الحاجة دي متعمولة قبل كده وبيستخدمها. الوحدة دي بتفتح لك عالم المكتبات: آلاف الأدوات الجاهزة اللي بتيجي مع بايثون.

الاستيراد (import) والوحدات درس 35

الهدف: تفهم إزاي تضيف قدرات جديدة لبرنامجك بسطر واحد.

1. إيه هي المكتبة؟

المكتبة (أو الوحدة / Module) هي ملف بايثون فيه دوال ومتغيّرات جاهزة كتبها ناس تانية. بايثون بتيجي معاها مكتبة قياسية ضخمة فيها أدوات لكل حاجة: العشوائية، التاريخ، الرياضيات، الملفات، الشبكات…

2. صيغ الاستيراد الأربعة

# 1) استيراد المكتبة كلها
import random
print(random.choice([1, 2, 3]))
# 2) استيراد دالة معيّنة بس
from random import choice
print(choice([1, 2, 3]))          # من غير random.
# 3) استيراد باسم مختصر
import random as rnd
print(rnd.choice([1, 2, 3]))
# 4) استيراد كل حاجة (غير منصوح بيه)
from random import *
print(choice([1, 2, 3]))
الصيغةالاستخدامالحكم

import random as rndrnd.choice()✅ مفيدة للأسماء الطويلة
from random import *choice()❌ بتلوّث المساحة وممكن تدهس أسماءك
import random as farid          # الاسم البديل حرّ تمامًا
list_names = ["farid", "mohammed", "randa"]
chosen_name = farid.choice(list_names)
print(chosen_name)

مكتبة random: العشوائية درس 36

الهدف: تولّد أرقام وتختار عناصر عشوائيًا — أساس كل الألعاب اللي جاية.

1. random.choice — اختيار عنصر واحد

import random
names = input("Enter your friend's names, please type a comma between each name\n").lower()
names_list = names.split(", ")
choice = random.choice(names_list)
print(f"Your friend that wins the game is {choice}")
▸ الناتج
Enter your friend's names: Ahmed, Sara, Ali
Your friend that wins the game is sara

لاحظ خط الإنتاج: input() ← .lower() ← .split(", ") ← random.choice(). كل خطوة بتشتغل على ناتج اللي قبلها.

2. random.choices — اختيار أكتر من عنصر (بتكرار)

import random
names = ["marwa", "abdallah", "mohammed", "sara"]
names_output = random.choices(names, k=3)
print(names_output)
▸ الناتج
['abdallah', 'marwa', 'abdallah']
⚠️ choices بتسمح بالتكرار!

لاحظ إن «abdallah» اتكرّر. لو عايز عناصر مختلفة استخدم random.sample(names, 3) — دي بتضمن عدم التكرار.

↩️ المثال ده بيكمّل على مثال قبله في نفس الدرس (بيستخدم random) — لو هتشغّله جوّه الصفحة، شغّل اللي قبله الأول.

print(random.choices(names, k=3))   # ممكن يتكرّر
print(random.sample(names, 3))      # مضمون مختلفين

4. random.shuffle — خلط القائمة

import random

shuffle بتعدّل القائمة في مكانها وبترجّع None — زي sort بالظبط. فما تكتبش names = random.shuffle(names).

الكمبيوتر جهاز حتمي — ما يقدرش يعمل حاجة عشوائية فعلًا. اللي بيحصل إنه بيستخدم معادلة رياضية بتبدأ من قيمة (اسمها seed، غالبًا الوقت الحالي) وبتطلّع أرقام تبدو عشوائية. عشان كده اسمها pseudo-random. لو عايز نفس النتيجة كل مرّة (للاختبار) استخدم random.seed(42) في أول البرنامج.

strftime = string format time: بتاخد «قالب» فيه أكواد بتبدأ بـ % وبتستبدلها بأجزاء التاريخ.

print(moment.strftime("%Y-%m-%d %H:%M"))
print(moment.strftime("%I:%M %p"))
print(moment.strftime("%A %d %B %Y"))
print(f"{moment:%d-%m-%Y}")

الكودالمعنىمثال

%mالشهر برقمين03

⚠️ فخ الحروف الكبيرة والصغيرة

%M = دقايق و %m = شهر. لو كتبت %Y-%M-%d هيطلع «2025-30-15» من غير أي خطأ — خطأ منطقي صامت.

6. مكتبة time: القياس والانتظار

datetime للتواريخ والمواعيد. أما time فللحاجات «التقنية»: توقيف البرنامج شوية، وقياس مدّة تنفيذ الكود.

import time
start = time.perf_counter()

مشروع 11: مولّد كلمات مرور قوية ◆ مشروع

الهدف: أول برنامج بيدمج 4 وحدات مع بعض: مدخلات + شروط + مكتبات + قوائم.

الفكرة

المستخدم بيحدّد طول كلمة السر وكام حرف وكام رقم وكام رمز. البرنامج بيتأكّد إن المجموع مظبوط، وبعدين بيولّد كل مجموعة ويخلطهم. 

import random
import string
length = int(input("Please enter your password length: "))
letters = int(input("Please enter the number of letters: "))
numbers = int(input("Please enter the number of numbers: "))
symbols = int(input("Please enter the number of symbols: "))
if (letters + numbers + symbols != length):
    print("Invalid inputs")
else:
    chars = string.ascii_letters
    numbers_password = string.digits
    symbols_password = string.punctuation
    strong_password = (random.choices(chars, k=letters) +
                       random.choices(numbers_password, k=numbers) +
                       random.choices(symbols_password, k=symbols))
    random.shuffle(strong_password)
    print("Your password is " + ''.join(strong_password))
▸ الناتج
Please enter your password length: 8
Please enter the number of letters: 4
Please enter the number of numbers: 2
Please enter the number of symbols: 2
Your password is $k2Bx#9a

الشرح خطوة بخطوة

  1. التحقّق: letters + numbers + symbols != length — لو المجموع مش مساوي الطول المطلوب، البرنامج بيرفض. ده اسمه validation وهو جزء أساسي من أي برنامج محترم.
  2. التوليد: تلات استدعاءات لـ random.choices، كل واحدة بترجّع قائمة.
  3. الدمج: علامة + بين القوائم بتلزّقهم في قائمة واحدة (زي دمج النصوص بالظبط).
  4. الخلط: من غير shuffle، كلمة السر هتبقى دايمًا: حروف الأول، بعدين أرقام، بعدين رموز — وده نمط متوقّع يضعف الأمان.
  5. الدمج النهائي: ''.join() بتحوّل القائمة لنص.

بسّط البرنامج: خلّي المستخدم يدخل الطول بس، والبرنامج يوزّع تلقائيًا (نص حروف، ربع أرقام، ربع رموز).

import random, string
length = int(input("طول كلمة السر: "))
letters = length // 2
numbers = length // 4

            random.choices(string.digits, k=numbers) +
            random.choices(string.punctuation, k=symbols))
random.shuffle(password)
print("".join(password))

⭐⭐تمرين 4 — choices ولا sample؟

عندك 5 جوايز و3 فايزين. أنهي دالة تستخدم عشان محدّش ياخد جايزتين؟ اكتب الكود ووضّح الفرق عمليًا.

شوف الحل 
import random
names = ["أحمد", "سارة", "علي", "منى", "خالد"]
# ❌ ممكن يتكرّر نفس الاسم
print(random.choices(names, k=3))
# ✅ مضمون مختلفين
print(random.sample(names, 3))

sample بتختار «بدون إرجاع»، choices بتختار «بإرجاع».

⭐⭐⭐تمرين 5 — مولّد كلمات سر ذكي

ولّد كلمة سر بطول يحدّده المستخدم، بحيث تضمن إن فيها على الأقل حرف كابيتال وحرف صغير ورقم ورمز — والباقي عشوائي من كل المجموعات.

شوف الحل 
import random
import string
length = int(input("طول كلمة السر (4 على الأقل): "))
if length < 4:
    print("لازم 4 على الأقل")
else:
    # نضمن واحد من كل نوع
    password = [
        random.choice(string.ascii_uppercase),
        random.choice(string.ascii_lowercase),
        random.choice(string.digits),
        random.choice(string.punctuation),
    ]
    # الباقي من كل المجموعات
    all_chars = string.ascii_letters + string.digits + string.punctuation
    password += random.choices(all_chars, k=length - 4)
    random.shuffle(password)
    print("".join(password))

الفكرة المهمّة: بنملأ الحد الأدنى المضمون الأول، وبعدين نكمّل الباقي، وبعدين نخلط. ده نمط بيتكرّر كتير في المشاكل اللي فيها «شروط لازم تتحقّق».

اختبار سريع

1. random.randint(1, 6) ممكن ترجّع 6؟

2. random.shuffle(lst) بترجّع…

3. random.choices(x, k=3) بترجّع…

4. string.ascii_letters طوله…

5. أنهي صيغة استيراد غير منصوح بيها؟
