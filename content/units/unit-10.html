القواميس والمجموعات: بيانات منظّمة بأسماء

القائمة بتوصل للعنصر برقمه — وstudent[1] مش بتقول لك يعني إيه. القاموس بيوصّل بالاسم: student["score"]. الوحدة دي بتكمّل صندوق أدواتك في تنظيم البيانات.

4. طباعة القواميس بشكل منسّق

def print_dicts_in_list(lst):
    result = []
    for item in lst:
        item_result = []
        for key, value in item.items():
            item_result.append(f"{key}: {value}")
        result.append("\n".join(item_result))
    return "\n\n".join(result)
sample_dicts = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25}
]
print(print_dicts_in_list(sample_dicts))
▸ الناتج
name: Alice
age: 30

name: Bob
age: 25

الدالة دي فيها حلقتين متداخلتين وقائمتين مؤقّتتين: واحدة لسطور القاموس الواحد، وواحدة لكل القواميس. وبعدين join مرّتين: "\n" بين سطور القاموس الواحد، و"\n\n" (سطر فاضي) بين القواميس. هنفهم كلمة def دي بالكامل في الوحدة الجاية.

        "text": "Who wrote 'Romeo and Juliet'?",

        "answer": "b"
    },
]
while True:
    score = 0
    for i, q in enumerate(questions, start=1):
        print(f"\nسؤال {i}/{len(questions)}: {q['text']}")
        for letter, choice in q["choices"].items():
            print(f"  {letter}. {choice}")
        while True:                                    # حلقة تحقّق موحّدة

    percent = round(score / len(questions) * 100)

        print("شكرًا للعب")
        break

تحدّيات بتصحيح آلي: الوحدة العاشرة 🧪 تحدّي

القواميس: عدّ، جمّع، ورتّب — أكتر 3 عمليات هتعملها على البيانات في حياتك.

🧪 التحدّي 1 — الكلمة الأكثر تكرارًا ⭐⭐

اطلب جملة، واطبع الأكثر تكرارًا: X (N) — من غير فرق بين الحروف الكبيرة والصغيرة، ولو فيه تعادل اختار الكلمة اللي ظهرت الأول.

شوف الحل النموذجي 
sentence = input("الجملة: ")
counts = {}
for word in sentence.lower().split():
    counts[word] = counts.get(word, 0) + 1
best, best_n = "", 0
for word, n in counts.items():
    if n > best_n:
        best, best_n = word, n
print(f"الأكثر تكرارًا: {best} ({best_n})")
🧪 التحدّي 2 — تجميع حسب المدينة ⭐⭐⭐

المدخل سطر زي sara:cairo ali:giza mona:cairo. اطبع كل مدينة في سطر (المدن مرتّبة أبجديًا) ومعاها أسماء سكّانها بترتيب ظهورهم:

▸ المطلوب
cairo: sara, mona
giza: ali
شوف الحل النموذجي 
pairs = input("البيانات: ").split()
groups = {}
for pair in pairs:
    name, city = pair.split(":")
    groups.setdefault(city, []).append(name)
for city in sorted(groups):
    print(f"{city}: {', '.join(groups[city])}")

⭐⭐تمرين 4 — دفتر تليفونات

اعمل قاموس أسماء وأرقام. خلّي المستخدم يبحث باسم، ويطبع الرقم أو رسالة «غير موجود». وخلّيه يفضل يبحث لحد ما يكتب «خروج».

phones = {
    "أحمد": "01011111111",
    "سارة": "01222222222",
    "علي": "01033333333",
}
while True:

    if name == "خروج":
        break
    number = phones.get(name)
    if number:
        print(f"📞 {name}: {number}")
    else:
        print(f"❌ '{name}' مش في الدفتر")

⭐⭐⭐تمرين 7 — نظام مخزون

اعمل قاموس منتجات {الاسم: {"price": …, "qty": …}}. اطبع تقرير فيه كل منتج وقيمته الإجمالية (السعر × الكمية)، وإجمالي قيمة المخزون، والمنتجات اللي كميتها أقل من 5.

شوف الحل 
inventory = {
    "شاي":  {"price": 25, "qty": 10},
    "قهوة": {"price": 40, "qty": 3},
    "سكر":  {"price": 15, "qty": 25},
    "عسل":  {"price": 90, "qty": 2},
}
total_value = 0
low_stock = []
print(f"{'المنتج':<8}{'السعر':>7}{'الكمية':>8}{'القيمة':>9}")
print("-" * 32)
for name, info in inventory.items():
    value = info["price"] * info["qty"]
    total_value += value
    if info["qty"] < 5:
        low_stock.append(name)
    print(f"{name:<8}{info['price']:>7}{info['qty']:>8}{value:>9}")
print("-" * 32)
print(f"إجمالي قيمة المخزون: {total_value}")
print(f"يحتاج إعادة طلب: {', '.join(low_stock)}")
