2. ليه with؟

# ❌ الطريقة القديمة — خطرة
file = open("names.txt", "r")
content = file.read()
file.close()          # لو حصل خطأ قبل السطر ده، الملف يفضل مفتوح!
# ✅ الطريقة الصح
with open("names.txt", "r") as file:
    content = file.read()
# الملف اتقفل تلقائيًا هنا، حتى لو حصل خطأ
🧠 ليه إغلاق الملف مهم؟
  • نظام التشغيل بيحدّد عدد الملفات المفتوحة — لو نسيت تقفل، ممكن يخلصوا.
  • عند الكتابة، البيانات بتفضل في ذاكرة مؤقّتة (buffer) وما بتتكتبش على الهارد غير عند الإغلاق. فلو ما قفلتش، ممكن تخسر بيانات.
  • في ويندوز، الملف المفتوح ممكن يبقى مقفول قدّام برامج تانية.

with بيضمن الإغلاق دايمًا. استخدمه دايمًا.

🧠 ليه .strip() ضرورية؟

كل سطر في الملف بينتهي بحرف السطر الجديد \n، و readlines() بترجّعه معاه. فمن غير strip النتيجة هتبقى ['أحمد\n', 'محمد\n', 'سارة']. و"أحمد\n" == "أحمد" بترجّع False! فأي مقارنة هتفشل.

3. إزالة فواصل معيّنة

with open("names.txt", "r") as file:
    content = [line.strip(", \n") for line in file.readlines()]
    print(content)
▸ الناتج
['أحمد', 'محمد', 'سارة']

strip(", \n") بتشيل الفواصل والمسافات وحرف السطر الجديد من الأطراف. لاحظ: بتشيل أي حرف من المجموعة دي، مش السلسلة كاملة. يعني strip(", \n") بتشيل فواصل ومسافات وسطور جديدة بأي ترتيب — ولو نسيت \n هتفضل لازقة في آخر كل كلمة.

1. الكتابة بوضع w+

🧠 إيه هي seek(0)؟

تخيّل الملف زي شريط كاسيت، وفيه «رأس قراءة» بيتحرّك. بعد ما تكتب، الرأس بيبقى في آخر اللي كتبته. فلو قريت على طول، هتقرا من الآخر = مفيش حاجة. seek(0) بترجّع الرأس لأول الملف عشان تقدر تقرا من الأول. 

  بعد write("mohammed ali"):
      m o h a m m e d   a l i
                              ▲ الرأس هنا
      read() → ""  (مفيش حاجة بعد الرأس)

  بعد seek(0):
      m o h a m m e d   a l i
      ▲ الرأس رجع للأول
      read() → "mohammed ali"  ✅
💥 تحذير: w+ بتمسح الملف!

السطر ده مسح كل اللي كان في names.txt قبل كده. لو كان فيه 100 اسم، راحوا كلهم.

ملفات CSV: الجداول اللي بتتبادل بين كل البرامج درس 66

الهدف: تقرا وتكتب ملفات CSV صح بمكتبة csv القياسية — وتفهم ليه split(",") هتكسرك أول ما البيانات تبقى حقيقية.

1. إيه هو CSV؟

Comma-Separated Values: ملف نصّي عادي، كل سطر = صف، والأعمدة مفصولة بفاصلة. Excel و Google Sheets وقواعد البيانات وكل مواقع التصدير بتتكلّمه. بسيط جدًا… لحد ما قيمة فيها فاصلة أو علامة تنصيص.

def to_json(obj):
    if isinstance(obj, date):

التعبيرات النمطية (Regular Expressions): البحث بالأنماط درس 70 · مهم

الهدف: توصف «شكل» النص اللي بتدوّر عليه بدل النص نفسه — عشان تستخرج أرقام تليفونات وتواريخ وإيميلات من أي كلام، وتتحقّق من المدخلات، وتنظّف وتعيد ترتيب النصوص في سطر واحد.

1. ليه محتاجين تعبيرات نمطية؟

دوال النصوص (find و split و isdigit) ممتازة لما تكون عارف النص نفسه. لكن لو السؤال: «هات كل أرقام الموبايل من الرسالة دي» — إنت مش عارف الأرقام، إنت عارف شكلها: «0 وبعدها 1 وبعدها 0 أو 1 أو 2 أو 5، وبعدها 8 أرقام». التعبير النمطي (Regex) هو لغة صغيرة لوصف الأشكال دي، ومكتبة re القياسية بتفهمها. 

  النمط:     0   1   [0125]   \d{8}
             │   │     │        └─ أي 8 أرقام
             │   │     └─ رقم واحد من دول بس
             │   └─ الرقم 1 بالظبط
             └─ الرقم 0 بالظبط

  بيطابق:   01012345678 ✓   01512345678 ✓
  ما بيطابقش: 01312345678 ✗ (013)   0101234 ✗ (قصير)

الهدف: تخزّن بياناتك في قاعدة بيانات حقيقية بدل ملفات النصوص وJSON، وتكتب أهم أوامر SQL، وتحمي برنامجك من أشهر ثغرة في التاريخ (SQL Injection).

1. ليه قاعدة بيانات؟

الملفات كويسة لحد ما البيانات تكبر: عايز «كل الطلاب اللي درجتهم فوق 80 من القاهرة مرتّبين»؟ مع ملف لازم تقرا كل حاجة وتفلتر بإيدك. قاعدة البيانات بتخزّن البيانات في جداول (زي Excel)، وبتسألها بلغة اسمها SQL — وهي تجيبلك النتيجة بسرعة، حتى مع ملايين الصفوف، ومن غير ما البيانات تبوظ لو اتنين كتبوا في نفس الوقت.

def analyze_file(path):
    """بترجّع قاموس فيه إحصائيات الملف"""
    try:
        with open(path, "r", encoding="utf-8") as file:
            content = file.read()
    except FileNotFoundError:
        print(f"الملف '{path}' مش موجود")
        return None
    lines = content.splitlines()
    words = content.split()
    return {
        "أحرف (بالمسافات)": len(content),
        "أحرف (بدون مسافات)": len(content.replace(" ", "").replace("\n", "")),
        "كلمات": len(words),
        "أسطر": len(lines),
        "أسطر غير فاضية": len([l for l in lines if l.strip()]),
        "مسافات": content.count(" "),
        "متوسط طول الكلمة": round(sum(len(w) for w in words) / len(words), 1) if words else 0,
        "أطول كلمة": max(words, key=len) if words else "-",
    }
def top_words(path, n=5):
    """بترجّع أكتر n كلمة تكرارًا"""
    with open(path, "r", encoding="utf-8") as f:
        words = f.read().lower().split()
    counter = {}
    for w in words:
        clean = w.strip(".,!?;:\"'()")
        if len(clean) > 2:
            counter[clean] = counter.get(clean, 0) + 1
    return sorted(counter.items(), key=lambda x: x[1], reverse=True)[:n]

def load_scores(path):
    result = {}
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            name, score = line.split(",")

def add_book(conn, title, year):
    with conn:
        cur = conn.execute("INSERT INTO books (title, year) VALUES (?, ?)", (title, year))

def books_after(conn, year):
    rows = conn.execute("SELECT title FROM books WHERE year > ? ORDER BY year", (year,)).fetchall()

🧪 التحدّي 3 — صيّاد أرقام الموبايل ⭐⭐⭐

extract_phones(text) بـ re: ترجّع أرقام الموبايل المصرية (010 أو 011 أو 012 أو 015 وبعدها 8 أرقام) بصيغة موحّدة تبدأ بـ 0، حتى لو مكتوبة بـ +20 أو 0020. من غير تكرار وبترتيب ظهورها، ومن غير ما تاخد جزء من رقم أطول.

شوف الحل النموذجي 
import re
PHONE = re.compile(r"(?<!\d)(?:\+20|0020|0)(1[0125]\d{8})(?!\d)")
def extract_phones(text):
    found = []
    for m in PHONE.finditer(text):
        number = "0" + m.group(1)
        if number not in found:
            found.append(number)
    return found

to_iso(text): حوّل كل تاريخ بصيغة DD/MM/YYYY جوّه النص لـ YYYY-MM-DD، والباقي زي ما هو. التاريخ لازم يكون يومه 01–31 وشهره 01–12 وكل جزء برقمين — غير كده سيبه.

شوف الحل النموذجي 
import re
DATE = re.compile(r"(?<!\d)(0[1-9]|[12]\d|3[01])/(0[1-9]|1[0-2])/(\d{4})(?!\d)")
def to_iso(text):
    return DATE.sub(r"\3-\2-\1", text)
🧪 التحدّي 6 — مذكّرات بتتحفظ JSON ⭐⭐⭐

كل مذكّرة قاموس فيه title (نص) و day (كائن date). save_notes(path, notes) تحفظها JSON بالعربي مقروء، و load_notes(path) ترجّعها بنفس الشكل (والـ day كائن date). لو الملف مش موجود أو بايظ، load_notes ترجّع [] من غير ما تقع.

شوف الحل النموذجي 
import json
from datetime import date
def save_notes(path, notes):
    data = [{"title": n["title"], "day": n["day"].isoformat()} for n in notes]
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
def load_notes(path):
    try:
        with open(path, encoding="utf-8") as f:
            data = json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        return []
    return [{"title": d["title"], "day": date.fromisoformat(d["day"])} for d in data]

مشروع 23: محلّل ملفات السجلّ (Log Analyzer) ◆ مشروع

الهدف: تقرا ملف سجلّ حقيقي الشكل بالتعبيرات النمطية، تتجاهل السطور البايظة، وتطلّع تقرير: الأخطاء لكل جزء، أكتر مشكلة متكرّرة، والمستخدمين المتأثّرين — وتصدّر الأخطاء لـ CSV.

الفكرة

كل تطبيق حقيقي بيكتب سجلّ (الوحدة 16). لما حاجة تبوظ، أول حاجة المبرمج بيعملها إنه يحلّل السجلّ. المشكلة: رسايل الأخطاء فيها أرقام متغيّرة («user 42» و «user 7»)، فمش هتعرف تعدّها كرسالة واحدة… إلا لو وحّدت الأرقام بـ re.sub.

الكود

import re
import csv
from collections import Counter
from pathlib import Path
SAMPLE = """\
2025-03-15 09:00:01 INFO [auth] User 7 logged in
2025-03-15 09:00:05 WARNING [payments] Slow response 2300ms
2025-03-15 09:01:10 ERROR [payments] Card declined for user 42
2025-03-15 09:02:44 ERROR [auth] Invalid token for user 13
this line is corrupted
2025-03-15 09:03:00 INFO [orders] Order 1001 created
2025-03-15 09:04:12 ERROR [payments] Card declined for user 7
2025-03-15 09:05:59 WARNING [orders] Slow response 1800ms
"""
LINE = re.compile(
    r"(?P<date>\d{4}-\d{2}-\d{2}) (?P<time>\d{2}:\d{2}:\d{2}) "
    r"(?P<level>INFO|WARNING|ERROR) \[(?P<module>\w+)\] (?P<message>.+)"
)
SLOW = re.compile(r"Slow response (\d+)ms")
USER = re.compile(r"user (\d+)", re.IGNORECASE)
def parse(path):
    records, bad = [], 0
    with open(path, encoding="utf-8") as f:
        for line in f:
            m = LINE.fullmatch(line.strip())
            if m:
                records.append(m.groupdict())
            else:
                bad += 1
    return records, bad
def normalize(message):
    return re.sub(r"\d+", "N", message)
Path("app.log").write_text(SAMPLE, encoding="utf-8")
records, bad = parse("app.log")
print(f"سطور سليمة: {len(records)} — سطور بايظة: {bad}")
levels = Counter(r["level"] for r in records)
print(dict(levels))
errors = [r for r in records if r["level"] == "ERROR"]
print("الأخطاء لكل جزء:", dict(Counter(r["module"] for r in errors)))
for msg, n in Counter(normalize(r["message"]) for r in errors).most_common():
    print(f"  {n}× {msg}")
slow = [int(m.group(1)) for r in records if (m := SLOW.search(r["message"]))]
print("أبطأ استجابة:", max(slow), "ms")
users = sorted({int(u) for r in errors for u in USER.findall(r["message"])})
print("مستخدمين اتأثّروا:", users)
with open("errors.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["date", "time", "module", "message"])
    writer.writeheader()
    for r in errors:
        writer.writerow({k: r[k] for k in writer.fieldnames})
print(Path("errors.csv").read_text(encoding="utf-8").splitlines()[:2])

الأفكار المهمّة

  • النمط المُجهّز بمجموعات بأسماء حوّل كل سطر لقاموس في خطوة — والباقي كله أدوات اتعلّمتها قبل كده.
  • fullmatch + عدّاد للبايظ: البرنامج ما بيقعش من سطر غلط، وفي نفس الوقت بيبلّغك إن فيه مشكلة في البيانات.
  • التوحيد بـ sub هو سرّ أدوات مراقبة الأخطاء الحقيقية: بتجمّع آلاف الأخطاء في عدد قليل من «الأنواع».
