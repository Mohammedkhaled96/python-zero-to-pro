حلقة while: كرّر لحد ما يحصل شرط

for بتلف على عدد معروف من العناصر. لكن لو مش عارف هتلف كام مرّة؟ زي «فضل تسأل المستخدم لحد ما يدخل إجابة صح»؟ هنا بيجي دور while — وهي اللي هتحوّل برامجك من سكريبتات لتطبيقات تفاعلية بجد.

حلقة while الأساسية درس 40

الهدف: تكرّر كود طول ما شرط معيّن صح.

دورة حياة while

لاحظ إن الناتج بدأ من 1 مش 0 — لأن x += 1 جاية قبل الـ print. ولاحظ إنه وصل لـ 10 رغم إن الشرط x <= 9، لأن في آخر دورة x كانت 9 (الشرط صح) فزوّدها لـ 10 وطبعها.

2. المكوّنات التلاتة اللي لازم تكون موجودة

  x = 0            ← [1] التهيئة: قيمة ابتدائية
  while x <= 9:    ← [2] الشرط: متى نستمر؟
      x += 1       ← [3] التحديث: لازم يقرّبنا لإنهاء الشرط!
      print(x)
نسيان أي واحدة = مشكلة
💥 الحلقة اللانهائية — أشهر كارثة
x = 0
while x <= 9:
    print(x)        # نسينا x += 1 !
# البرنامج هيفضل يطبع 0 للأبد 🔁

لو حصل ده، اضغط Ctrl + C في الـ Terminal عشان توقّف البرنامج.
قبل ما تشغّل أي while، اسأل نفسك: «إيه اللي هيخلّي الشرط يبقى False؟»

الحلقات المتداخلة (Nested Loops) درس 42

الهدف: حلقة جوّه حلقة — أساس «إعادة اللعب» وأي بنية ثنائية الأبعاد.

1. الفكرة

for i in range(1, 4):
    for j in range(1, 4):

    print("--- انتهت الدورة الخارجية ---")

🧠 القاعدة

الحلقة الداخلية بتخلّص دورتها كاملة في كل خطوة من الحلقة الخارجية. فلو الخارجية 3 دورات والداخلية 3، الإجمالي 9 تنفيذات.

2. نمط «إعادة اللعب» — أهم استخدام عملي

  while True:              ← الحلقة الخارجية: الجولات
      while True:          ← الحلقة الداخلية: جولة واحدة
          ...              ← منطق اللعبة
          break            ← ينهي الجولة الحالية

      again = input("تلعب تاني؟")
      if again == "no":
          break            ← ينهي البرنامج كله
النمط اللي هتستخدمه في كل ألعاب الوحدة دي
⚠️ break بتكسر الحلقة اللي هي جوّاها بس

break في الحلقة الداخلية ما بتخرجش من الخارجية. دي بالظبط الميزة اللي بتخلّي النمط ده يشتغل: بنخرج من الجولة، وبنسأل «تلعب تاني؟»، ولو لأ بنخرج من الخارجية كمان.

3. مثال بسيط على النمط

import random
while True:                                     # الجولات
    while True:                                 # جولة واحدة
        guess = input("خمّن: صورة ولا كتابة؟ ").strip()
        if guess in ["صورة", "كتابة"]:
            break
        print("اختيار غير صحيح، جرّب تاني")
    coin = random.choice(["صورة", "كتابة"])
    if guess == coin:
        print(f"كسبت! العملة طلعت {coin}")
    else:
        print(f"خسرت. العملة طلعت {coin}")
    again = input("تلعب تاني؟ (yes/no) ").strip().lower()
    if again == "no":
        print("شكرًا لك، لحد ما نشوفك تاني")
        break
    print("تمام، يلا بينا")
▸ الناتج
خمّن: صورة ولا كتابة؟ ورقة
اختيار غير صحيح، جرّب تاني
خمّن: صورة ولا كتابة؟ صورة
كسبت! العملة طلعت صورة
تلعب تاني؟ (yes/no) no
شكرًا لك، لحد ما نشوفك تاني

لاحظ إن الحلقة الداخلية دورها التحقّق من صحة المدخل، والخارجية دورها تكرار اللعبة. فصل المسؤوليات ده بيخلّي الكود مفهوم.

4. الخروج من حلقتين مرّة واحدة

break بتكسر أقرب حلقة بس. لو لقيت اللي بتدوّر عليه جوّه الحلقة الداخلية، الخارجية هتكمّل. الحل الأوضح: راية.

grid = [[3, 8, 1], [9, 4, 7], [5, 6, 2]]
target = 4
found = False
for r, row in enumerate(grid):
    for c, value in enumerate(row):
        if value == target:
            found = True
            break
    if found:
        break
print(f"الصف {r} العمود {c}" if found else "مش موجود")
▸ الناتج

5. while...else

نفس فكرة for...else: الـ else بتتنفّذ لو الشرط بقى False والحلقة خلصت من غير break.

secret = "1234"
guesses = ["0000", "1111", "1234"]
attempts = 0
while attempts < 3:
    guess = guesses[attempts]
    attempts += 1
    if guess == secret:
        print(f"اتفتح بعد {attempts} محاولات")
        break
else:
    print("الحساب اتقفل 🔒")

ملاحظة على continue هنا

ℹ️ الـ continue الأخيرة زايدة

هي آخر سطر في جسم الحلقة، فالحلقة كانت هتلف تاني على أي حال. وجودها مش خطأ، لكنه بيوهم القارئ إن فيه كود بعدها هيتخطّى. القاعدة: استخدم continue لما فيه كود فعلًا بعده عايز تتخطّاه.

النسخة المطوّرة: منافسة حقيقية

import random
CHOICES = ["king", "ketaba"]
score = {"you": 0, "computer": 0}
print("لعبة ملك أم كتابة — الأول اللي يوصل 3 نقاط يكسب")
while score["you"] < 3 and score["computer"] < 3:
    while True:
        user = input("اختر king أو ketaba: ").strip().lower()
        if user in CHOICES:
            break
        print("اختيار غير صحيح")
    coin = random.choice(CHOICES)
    print(f"العملة طلعت: {coin}")
    if user == coin:
        score["you"] += 1
        print("👑 نقطة لك!")
    else:
        score["computer"] += 1
        print("💻 نقطة للكمبيوتر")
    print(f"النتيجة: أنت {score['you']} - الكمبيوتر {score['computer']}\n")
if score["you"] == 3:
    print("🎉 مبروك، إنت الفائز!")
else:
    print("😔 الكمبيوتر كسب، حظ أوفر")

استخدمنا هنا قاموس score عشان نخزّن النتيجتين بأسماء واضحة، وشرط الحلقة نفسه بقى شرط الفوز. القواميس هي موضوع الوحدة 10.

تحدّيات بتصحيح آلي: الوحدة الثامنة 🧪 تحدّي

حلقات while: الاختبار الأهم دايمًا — هل الحلقة بتقف في الوقت الصح؟

🧪 التحدّي 1 — متتالية كولاتز ⭐⭐

ابدأ برقم n: لو زوجي اقسمه على 2، لو فردي اضربه في 3 وزوّد 1. كرّر لحد ما توصل 1. اطبع عدد الخطوات: N. (6 ← 3 ← 10 ← 5 ← 16 ← 8 ← 4 ← 2 ← 1 = 8 خطوات)

شوف الحل النموذجي 
n = int(input("الرقم: "))
steps = 0
while n != 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1
    steps += 1
print(f"عدد الخطوات: {steps}")
🐞 التحدّي 2 — تخمين بلا نهاية ⭐⭐

المفروض اللاعب ياخد 3 محاولات بس يخمّن فيهم الرقم 7. البرنامج ده ما بيوقفش أبدًا بعد 3 محاولات. صلّحه.

شوف الحل النموذجي 
secret = 7
attempts = 0
while attempts < 3:
    guess = int(input("خمّن: "))
    attempts += 1
    if guess == secret:

        break
else:

⭐⭐تمرين 3 — قائمة تسوّق

خلّي المستخدم يضيف أصناف لقائمة واحدًا واحدًا. لما يكتب «تم» توقّف واطبع القائمة مرقّمة وعدد الأصناف.

شوف الحل 
items = []
while True:
    item = input("اكتب صنف (أو 'تم' للإنهاء): ").strip()
    if item == "تم":
        break
    if not item:
        print("ما كتبتش حاجة")
        continue
    items.append(item)
    print(f"✅ اتضاف: {item}")
print(f"\nقائمتك ({len(items)} صنف):")
for i, item in enumerate(items, start=1):
    print(f"  {i}. {item}")
⭐⭐تمرين 4 — مجموع تراكمي

اطلب أرقام من المستخدم واحدًا واحدًا، واجمعها. لما يكتب 0 توقّف واطبع المجموع والمتوسط وعدد الأرقام.

شوف الحل 
total = 0
count = 0
while True:
    n = float(input("اكتب رقم (0 للإنهاء): "))
    if n == 0:
        break
    total += n
    count += 1
if count == 0:
    print("ما دخلتش أي رقم")
else:
    print(f"المجموع: {total}")
    print(f"عدد الأرقام: {count}")
    print(f"المتوسط: {total / count:.2f}")

لاحظ: فحص count == 0 ضروري، وإلا هتقسم على صفر.
