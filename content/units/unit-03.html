النصوص بعمق: الفهرسة، التقطيع، والدوال الجاهزة

النص مش مجرّد كلام — هو سلسلة حروف مرقّمة تقدر توصل لأي جزء منها. الوحدة دي بتفتح لك باب التعامل الاحترافي مع النصوص، وهي أساس نص الوحدات الجاية: تقسيم المدخلات، التشفير، تحليل الملفات، كل ده بيبدأ من هنا.

الفهرسة (Indexing): الوصول لحرف واحد درس 13

الهدف: تجيب أي حرف من نص برقمه، وتفهم ليه بايثون بتبدأ من صفر.

1. كل حرف له رقم

       p    y    t    h    o    n
       ↑    ↑    ↑    ↑    ↑    ↑
 موجب  0    1    2    3    4    5
 سالب -6   -5   -4   -3   -2   -1
كلمة python بفهارسها الموجبة والسالبة
word = "python"
print(word[0])     # p   ← أول حرف
print(word[3])     # h
print(word[5])     # n   ← آخر حرف
▸ الناتج
p
h
n
🧠 ليه الترقيم بيبدأ من 0 مش 1؟

السبب من أيام لغة C: الفهرس في الحقيقة معناه «كام خانة أبعد من بداية النص؟». أول حرف بعده صفر خانات من البداية، فهو رقم 0. الحرف التاني بعده خانة واحدة، فهو 1. الفكرة دي موجودة في أغلب لغات البرمجة (بايثون، C، Java، JavaScript)، فاتعوّد عليها من دلوقتي.

2. الفهرسة السالبة — ميزة بايثون

word = "python"
print(word[-1])    # n   ← آخر حرف
print(word[-3])    # h   ← تالت حرف من الآخر
▸ الناتج
n
h

ده أنضف بكتير من word[len(word) - 1]، ومش محتاج تعرف طول النص أصلًا. قاعدة سهلة: -1 دايمًا آخر عنصر.

3. الخطأ الشهير IndexError

word = "python"          # 6 حروف، الفهارس من 0 لـ 5
print(word[6])           # ❌ IndexError: string index out of range
💥 قاعدة سهلة

أكبر فهرس صالح = len(text) - 1. عدد الحروف 6 يعني آخر فهرس 5. الخطأ ده هيقابلك كتير جدًا، وأول ما تشوفه اسأل نفسك: «الفهرس ده أكبر من الطول ناقص واحد؟»

4. النصوص غير قابلة للتعديل (Immutable)

word = "python"
print(word[0])       # p   ← القراءة شغّالة
word[0] = "P"        # ❌ TypeError: 'str' object does not support item assignment

افتكر من درس الذاكرة: str نوع immutable. لو عايز تغيّر حرف، بتعمل نص جديد: 

word = "python"
new_word = "P" + word[1:]       # ناخد الباقي ونلزّق حرف جديد قدّامه
print(new_word)                 # Python
print(word.replace("p", "P"))   # أو نستخدم replace
▸ الناتج
Python
Python

  • النصوص غير قابلة للتعديل: بتعمل نص جديد بدل ما تعدّل.

التقطيع (Slicing): استخراج جزء من النص درس 14

الهدف: تتقن الصيغة [start:end:step] — أقوى أداة نصّية في بايثون.

1. الصيغة الأساسية

   text[ start : end : step ]
          │      │      │
          │      │      └── الخطوة (اختيارية، الافتراضي 1)
          │      └───────── نهاية (غير مشمولة!)
          └──────────────── بداية (مشمولة)
أجزاء التقطيع التلاتة
word = "python"
print(word[0:3])   # pyt     ← الفهارس 0,1,2  (3 مش مشمول)
print(word[0:5])   # pytho   ← الفهارس 0..4
print(word[2:5])   # tho
▸ الناتج
pyt
pytho
tho
⚠️ النهاية غير مشمولة — أهم نقطة

word[0:3] بترجّع 3 حروف بس (0، 1، 2) — الفهرس 3 مش منها.
القاعدة السريعة: عدد الحروف الراجعة = end − start.
الفايدة: word[0:3] + word[3:] بيرجّعوا النص كامل من غير تكرار ولا نقص.

2. حذف الأطراف

word = "python"
print(word[0:])    # python   ← من البداية للنهاية
print(word[:3])    # pyt      ← من الأول لحد 3
print(word[2:])    # thon     ← من 2 للآخر
print(word[:])     # python   ← نسخة كاملة
▸ الناتج
python
pyt
thon
python

3. التقطيع بالفهارس السالبة

word = "python"
print(word[-4:-1])   # tho    ← من -4 لحد -1 (مش مشمول)
print(word[-3:])     # hon    ← آخر 3 حروف
print(word[:-2])     # pyth   ← كل حاجة ما عدا آخر حرفين
▸ الناتج
tho
hon
pyth

4. الخطوة (step) وعكس النص

word = "python"
print(word[::2])     # pto     ← حرف وسيب حرف
print(word[1::2])    # yhn     ← من الفهرس 1، حرف وسيب حرف
print(word[::-1])    # nohtyp  ← عكس النص كامل!
▸ الناتج
pto
yhn
nohtyp
💡 [::-1] — أشهر حيلة في بايثون

خطوة سالبة معناها «امشِ للورا»، فبتقرا النص من الآخر للأول. هتلاقيها في كل كود بايثون في الدنيا، وبتشتغل على القوائم كمان مش النصوص بس.

5. التقطيع ما بيرميش أخطاء

word = "python"
print(word[10])      # ❌ IndexError
print(word[2:100])   # ✅ "thon"  — بترجّع اللي موجود بس
print(word[100:])    # ✅ ""      — نص فاضي

الفهرسة بحرف واحد بترمي خطأ لو خرجت عن الحدود، لكن التقطيع بيتصرّف بهدوء وبيرجّع اللي متاح. الفرق ده مفيد لكن ممكن يخبّي عنك أخطاء منطقية، فخلي بالك.

6. تطبيق عملي: آخر رقمين من التليفون

4. التقسيم والدمج — split و join

الاتنين دول من أهم دوال بايثون على الإطلاق، وهنستخدمهم في نص المشاريع الجاية.

split — من نص لقائمة

print(words)
▸ الناتج

▸ الناتج

⚠️ الفاصل لازم يطابق بالظبط

split(", ") بفاصلة ومسافة ≠ split(",") بفاصلة بس. لو المستخدم كتب "ahmed,mohammed" من غير مسافة، الأولى هترجّع عنصر واحد بس! الحل الآمن: [n.strip() for n in text.split(",")] — بنقسم على الفاصلة وبعدين ننضّف كل عنصر.

حيلة: تكرار كلمة بفاصل

الهدف: تحوّل بين الحرف ورقمه في Unicode — أساس التشفير اللي هنبنيه بعدين.

print(chr(100))    # d       ← الرقم → حرفه

دوال نصوص متقدّمة: المحاذاة، التقسيم الذكي، والاستبدال الجماعي درس 17

الهدف: تكمّل صندوق أدوات النصوص بالدوال اللي بتفرق بين كود «شغّال» وكود «احترافي» — ومنها فخاخ بيقع فيها ناس بخبرة سنين.

1. المحاذاة والحشو: center و ljust و rjust و zfill

لما تطبع جدول أو فاتورة في الـ Terminal، محتاج كل عمود ياخد عرض ثابت. الدوال دي بتكمّل النص بمسافات (أو أي حرف تختاره) لحد عرض معيّن.

print("[" + "Python".rjust(12, "-") + "]")

⚠️ الحروف العربية والمحاذاة

المحاذاة بتعدّ عدد الحروف مش عرضها على الشاشة. الحروف العربية بالتشكيل، والإيموجي، والحروف الصينية ممكن تبوّظ الاصطفاف لأن عرضها المرئي مختلف. للجداول العربية المعقّدة استخدم مكتبة زي rich أو tabulate لاحقًا.

2. partition: قسّم عند أول ظهور — وارجع بـ 3 أجزاء دايمًا

split بترجّع عدد أجزاء متغيّر، وده بيعمل مشاكل لو الفاصل مش موجود. partition بترجّع دايمًا 3 أجزاء: اللي قبل الفاصل، الفاصل نفسه، اللي بعده. 

email = "ahmed.ali@company.com"
user, sep, domain = email.partition("@")
print(user)
print(domain)
print("no-at-sign".partition("@"))
path = "photos/2024/trip/beach.jpg"

تشريح السطر الأخير

  separator.join( [word] * times )
      │              │       │
      │              │       └── 3
      │              └────────── ["Python"]
      │
      │        [word] * times  →  ["Python", "Python", "Python"]
      │
      └── "-".join([...])      →  "Python-Python-Python"
من الداخل للخارج

ملاحظات على الجودة

  • int() ضرورية حوالين times لأن [word] * "3" هيرمي TypeError.
  • استخدمنا الاسم جوّه رسايل الـ input نفسها عن طريق f-string — ده بيدّي إحساس شخصي للبرنامج.
  • لو المستخدم كتب حروف في عدد المرّات، البرنامج هيقع. هنحصّنه في الوحدة 9.
✍️ التحدّي

↩️ المثال ده بيكمّل على مثال قبله في نفس الدرس (بيستخدم separator) — لو هتشغّله جوّه الصفحة، شغّل اللي قبله الأول.

المستوى الأول

⭐تمرين 1 — تشريح كلمة

عندك word = "programming". اطبع: أول حرف، آخر حرف، أول 4 حروف، آخر 4 حروف، الكلمة معكوسة، وعدد حروفها.

⭐تمرين 2 — تنظيف مدخل

⭐تمرين 3 — split و join

حوّل "أحمد-سارة-علي-منى" لقائمة، وبعدين ارجّعها نص لكن مفصولة بـ « و ».

شوف الحل 
text = "أحمد-سارة-علي-منى"

المستوى الثاني

⭐⭐تمرين 4 — إخفاء الإيميل

عندك إيميل. اطبعه مخفي جزئيًا: أول حرفين + نجوم + @ + الدومين. مثال: farid5006@gmail.com ← fa*******@gmail.com

شوف الحل 
email = "farid5006@gmail.com"
user, domain = email.split("@")
hidden = user[:2] + "*" * (len(user) - 2)
print(f"{hidden}@{domain}")      # fa*******@gmail.com

لاحظ التفكيك المباشر user, domain = email.split("@") — بيشتغل لأن split رجّعت عنصرين بالظبط.

⭐⭐تمرين 5 — تشفير حرف

اطلب حرف ورقم مفتاح من المستخدم، واطبع الحرف مشفّرًا وبعدين مفكوكًا للتأكّد إنه رجع زي ما كان.

شوف الحل 
char = input("حرف: ")
key = int(input("المفتاح: "))
encrypted = chr(ord(char) + key)
decrypted = chr(ord(encrypted) - key)
print(f"الأصلي: {char} (رقمه {ord(char)})")
print(f"المشفّر: {encrypted}")
print(f"بعد الفك: {decrypted}")
⭐⭐تمرين 6 — الأحرف الأولى

عندك "محمد خالد محمود". اطبع الأحرف الأولى مفصولة بنقط: م.خ.م — من غير حلقة تكرار (استخدم split والفهرسة).

شوف الحل 
name = "محمد خالد محمود"
parts = name.split()
print(f"{parts[0][0]}.{parts[1][0]}.{parts[2][0]}")

بعد الوحدة 6 هتقدر تكتبها بشكل يشتغل مع أي عدد أجزاء: ".".join(p[0] for p in parts)

المستوى الثالث

⭐⭐⭐تمرين 7 — محلّل نص

اطلب جملة من المستخدم واطبع: عدد الحروف، عدد الكلمات، عدد المسافات، الجملة بحروف كابيتال، الجملة معكوسة، وهل فيها كلمة «python» (بغض النظر عن حالة الحروف).

⭐⭐⭐تمرين 8 — مولّد رمز الحجز

اطلب اسم المدينة وتاريخ بصيغة 2026-09-08، وولّد كود بالشكل: أول 3 حروف من المدينة كابيتال + الشهر + اليوم. مثال: Cairo / 2026-09-08 ← CAI0908
